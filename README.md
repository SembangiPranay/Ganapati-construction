# S Ganapati Construction

A modern web application for S Ganapati Construction, showcasing industrial construction, structural steel fabrication, erection, and heavy equipment works.

## Tech Stack

- **React 19**
- **Vite 8**
- **Tailwind CSS v4**
- **TypeScript**

## Getting Started

### 1. Install Dependencies
```bash
npm install
```
*(or using pnpm: `pnpm install`)*

### 2. Run the Development Server
```bash
npm run dev
```

Open [http://localhost:8443](http://localhost:8443) (or your configured port) in your browser.

### 3. Build for Production
```bash
npm run build
```

### 4. Preview Production Build
```bash
npm run preview
```
